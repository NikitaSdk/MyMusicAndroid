# MyMusic для Android

Учебный проект (лабораторная работа), личное некоммерческое использование.
Поиск музыки, прослушивание онлайн, фоновое воспроизведение с выключенным экраном,
медиатека, плейлисты, скачивание для офлайна.

## Стек
- Kotlin + Jetpack Compose (Material 3), тёмная тема
- Media3 ExoPlayer + MediaSessionService — фон, уведомление, экран блокировки, наушники
- NewPipeExtractor — поиск (YouTube Music) и аудиопотоки, без API-ключей
- OkHttp — сеть и скачивание; JSON-файл — медиатека и плейлисты
- Coil — обложки; GitHub Actions — сборка APK

## Структура
```
app/src/main/java/com/nikitasdk/mymusic/
  App.kt, MainActivity.kt      запуск, навигация
  data/                        YouTube, медиатека, загрузки, сеть
  playback/                    фоновый сервис и связь с UI
  ui/                          экраны: поиск, медиатека, плейлисты, плеер
.github/workflows/build.yml    сборка APK
```

## Сборка и установка
1. Загрузить содержимое папки в репозиторий GitHub → вкладка Actions → сборка «Build APK».
2. Скачать артефакт `MyMusic-apk` → внутри `MyMusic.apk`.
3. Отправить APK себе в Telegram → открыть на телефоне → разрешить установку из Telegram.
4. Xiaomi/HyperOS: Настройки → Приложения → MyMusic → Контроль активности → «Нет ограничений».

Обновления ставятся поверх, данные сохраняются (ключ подписи `app/release.keystore` постоянный).

> Получение аудио в обход официального плеера нарушает правила YouTube.
> Проект учебный, только для личного использования.
